# Indkøbsliste-app

En simpel React Native-app (Expo) til at holde styr på en indkøbsliste.
Lavet til Godkendelsesopgave 1 (INNT).

## Funktioner
- Forside med navigation til liste og "om appen"
- Indkøbsliste (FlatList) hvor man kan tilføje varer og fjerne dem igen
- Separat styling-fil (`styles/styles.js`)

## Kør appen lokalt
```
npm install
npx expo start
```
Scan QR-koden med Expo Go-appen (iOS/Android).
